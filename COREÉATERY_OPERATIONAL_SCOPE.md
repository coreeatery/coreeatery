# COREÉATERY Operational Scope

## Included

- Public Website
- Homepage CMS
- Menu Management
- Reservation
- Cashier POS
- Basic Sales Reporting
- Admin and Cashier Roles

## Not Included in Initial Go-Live

- Inventory
- Purchasing
- Advanced Finance
- CRM
- Mobile Application
- Advanced Automation

## MVP Reservation Rules

- Operating hours are 10:00–22:00 WIB.
- Customers select generated 30-minute slots from 10:00 through 21:30.
- A booking is allocated to the smallest active table that fits the party.
- The initial table configuration supports one-table parties up to the largest active table capacity.
- Combining tables is out of scope until the owner approves the allocation policy.

## Go-Live Preconditions

- Owner approves this scope and the current table/capacity data.
- Client UAT is completed by an owner, admin, and cashier account.
- The named production deployment and database migration are recorded in the release log.
- Client contact, backup operator, and fallback payment/reservation procedure are agreed.
