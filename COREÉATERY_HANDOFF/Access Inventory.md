# Access Inventory

Keep this file free of passwords, tokens, recovery codes, and personal secrets.

| Access area | Account owner | Purpose | Review cadence |
|---|---|---|---|
| Vercel project | Client owner / technical owner | Production deployment | Before every release |
| Supabase project | Client owner / technical owner | Database, Auth, Storage | Monthly |
| Admin application | Named admin users | CMS, menu, reservations | Monthly |
| Cashier application | Named cashier users | Orders and payments | At staff changes |
| Domain/DNS | Client owner | Public website routing | Before DNS changes |

## Operating rules

- Create one named account per person.
- Remove or deactivate access immediately when staff leave.
- Store credentials in an approved password manager, never in this repository or chat.
- Record the responsible owner and recovery process in the client's private access register.
