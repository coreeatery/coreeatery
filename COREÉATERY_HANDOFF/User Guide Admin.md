# User Guide Admin

## Daily access

1. Open the approved production URL and sign in with your own account.
2. Use **Admin** only for homepage content, menu, gallery, promotions, reservations, and approved settings.
3. Do not share credentials or use a cashier account for admin work.

## Homepage CMS

1. Open **Admin → Homepage**.
2. Enter Indonesia, English, and 中文 content as needed.
3. Upload or replace the hero/about image, then choose **Simpan Homepage**.
4. Refresh the public homepage and check each language before announcing changes.

## Menu and reservations

- Keep an item active and available only while it can be sold.
- Review pending reservations, then change status only after the customer is handled.
- Do not alter a reservation's table/time through raw database tools; use the approved application workflow.

## Escalation

Capture the page, time, account role, and error text. Contact the designated technical support contact before retrying a payment or changing database data.
